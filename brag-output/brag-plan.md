# Brag Plan: DEYOUNG COMMUNICATION

## What is this app?
DEYOUNG COMMUNICATION is a platform for hiring AI voice employees (receptionist, sales assistant, support agent) that answer every call and chat with real spoken voice, emotion carried in prosody, true barge-in, and measured latency — built on an honesty principle: nothing is claimed that was not tested.

## The angle
The product IS a phone call. So the film is one: open inside a live call on the product's own hero phone, pull back to its promise, then dive into the real console where a real recorded exchange plays out — including the differentiator nobody else has: you can speak mid-sentence and it stops. Close on the honesty system that makes it credible. "A live call, seen."

## Hook (first 2-3 seconds)
No logo, no slogan, no fade-in. Frame 0 is already inside the product's live-call phone screen: dark ink wallpaper, cerulean aurora, "9:41", a pulsing cyan ring around the AI receptionist avatar "AD · Ada · AI Receptionist · on the line", a timer chip counting, and a glossy studio waveform already dancing. The waveform is alive before the viewer is — instant curiosity: what is this call?

## Key moments (the middle)
- The real headline lands over the phone: "Hire intelligence that never puts a caller on hold."
- The dive into the real console: YOU bubble types "Hi, do you take bookings on Sundays?" (real customer message), cyan thinking dots, then Ada's real reply — "Yes, we take bookings on Sundays from 9:00 to 14:00. Would you like to schedule an appointment?" — with the real measured latency chip 2092MS and the spoken checkmark.
- THE BARGE-IN (on the music's strongest cue at 8.74s): the human speaks again mid-reply; Ada's bubble snaps to the INTERRUPTED state. Caption: "Speak mid-sentence. It stops."
- Three real employee cards arrive one by one: Receptionist / Sales assistant / Support agent, each with its real photo and real one-liner.
- The honesty system: giant "NO FAKE NUMBERS" with the site's real trust tags, and the line the product lives by: "Feeling is carried in the voice, never read out."

## Outro / punchline
The monogram D (stem + three staggered voice bars, middle bar in the cerulean-to-cyan gradient) draws itself in, DEYOUNG COMMUNICATION wordmark, tagline "AI EMPLOYEES FOR REAL CONVERSATIONS", CTA pill "Start building free". Bell resolves. Hold.

## User flow worth showing
Entry → key action → result, all real:
1. A call is live on the AI employee's phone screen (the site's own hero phone UI: caller identity, timer, waveform, stats rail).
2. In the console the customer asks "Hi, do you take bookings on Sundays?" (real message from the live database) and Ada answers from her real instructions (real reply, 2092ms measured).
3. The customer interrupts mid-sentence; the turn is marked INTERRUPTED — the barge-in promise, shown working.
4. Result: three deployable roles + your own cloned voice, honest by construction.

## Reproduce (exact commands)

From the repository root:

```bash
# 1. Assets were prepared once (already committed):
#    - fonts copied from the site build to composition/assets/fonts/
#    - agent photos copied from public/img/ to composition/assets/img/
#    - music (happy-beats-business-moves-vol-12, Ende) + cues json via hyperframes beats preset
#    - music bands pre-extracted for audio-reactive breathing (first 20s, trimmed to 8 bands)
python3 - <<'PY'
import json
d = json.load(open('brag-output/composition/assets/audio-data/music-bands.json'))
frames = d['frames'][:600]
out = {'fps': 30, 'totalFrames': len(frames), 'frames': [
    {'t': round(f['time'], 4), 'r': round(f['rms'], 4), 'b': [round(x, 3) for x in f['bands'][:8]]} for f in frames]}
open('brag-output/composition/assets/audio-data/music-bands-20s.js', 'w').write(
    'window.MUSIC_BANDS = ' + json.dumps(out, separators=(',', ':')) + ';')
PY

# 2. Validate (single gate): lint + runtime + layout + motion + WCAG contrast
cd brag-output/composition && npx --yes hyperframes@0.8.50 check

# 3. Render (19.5s, 1080x1920, 30fps, delivery quality, PNG frames for color-true UI)
npx --yes hyperframes@0.8.50 render --quality delivery --fps 30 \
  --video-frame-format png --output ../brag.mp4

# 4. Verify
ffprobe -v error -show_entries format=duration -show_entries stream=codec_type,width,height,r_frame_rate ../brag.mp4
```

Environment used: Node 22, system FFmpeg 7.1.5, local Chromium via Puppeteer (software
GPU — no hardware encoder available in this sandbox; `--gpu` was not used). GSAP 3.14.2
is vendored locally at `composition/assets/js/gsap.min.js` so the render performs no
network fetches.

## Implementation notes (deviations from the storyboard, both QA-driven)

- The caller's mini bubble is visible from frame 0 (storyboard had both bubbles arriving
  during Scene 2). At the hook the phone otherwise had a 450px dead zone between the
  timer and the BARGE-IN chip; showing the already-asked question is the honest state of
  a 0:07 call and fills the frame. Ada's reply still arrives during the promise scene
  with the glass shimmer, as planned.
- The phone's call-control row (mic, keypad, waveform, end call — cerulean, never red)
  was added below the waveform for bottom-weight balance, matching the real screen.
